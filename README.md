# The Daily Journal 📝

A simple, responsive multi-page blog website built using HTML and CSS. The website features a clean, warm, and minimal design, with a focus on sharing articles and providing an easy browsing experience.

## 🌐 Live Demo

[View The Daily Journal](https://ilhambatool.github.io/tsg-webdev-p03-IlhamBatool/)

## 📂 GitHub Repository

[View Source Code](https://github.com/ilhambatool/tsg-webdev-p03-IlhamBatool)

## ✨ Features

- **Home Page:** A welcoming hero section and featured blog posts.
- **Blog Page:** Displays four blog posts with images, titles, dates, and short descriptions.
- **Contact Page:** Includes contact information and a contact form.
- **Shared Navigation:** Easy navigation between all three pages.
- **Consistent Design:** A shared stylesheet maintains the same design across the website.
- **Responsive Layout:** Adapts to different screen sizes, including mobile devices.
- **Hover Effects:** Interactive styling for navigation links and buttons.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts / Unsplash images

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/ilhambatool/tsg-webdev-p03-IlhamBatool.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 📌 Project Purpose

This project was created as **Project 03 – Beginner Level** to practice building a multi-page website using HTML and CSS.

It focuses on page linking, reusable styling, website structure, and responsive design.
